# Проверка китайского текста главы I

Статус `zh_CN` в `localization/strings.csv`: **черновой перевод, без вычитки носителем языка**.
Наличие строки и прохождение `validate_data.gd` подтверждают только полноту локализации, не стиль.

В первую очередь попросить носителя проверить новые условные реплики:

- `DLG_AGNES_SEVERIN_*` — слова Агнессы после выбора у Северина;
- `DLG_MARA_AGNES_*` — реакция Мары на ответы Агнессе;
- `DLG_CRONE_MARA_*` — реакция старухи на выбор у Мары;
- `DLG_MATTHEW_CRONE_*` — ответ Матфея о старухе;
- `DLG_CH1_PREACHER_VOICE_*` — Проповедник после Голоса;
- `DLG_CH1_FINALE_BELL_*` — колокол в финале.
- `DLG_CH1_PREACHER_MERCY_*`, `DLG_MATTHEW_ROAD`, `DLG_MATTHEW_NAMES`,
  `DLG_MATTHEW_R_NAMES`, `DLG_CH1_OPHANIM_FALL_3`, `DLG_CH1_FINALE_NAMES` —
  новые библейские мотивы; проверить, что это художественные намёки, а не выдаваемые за цитату слова.

Затем проверить прежние строки главы I (`DLG_CH1_*`, `DLG_SEVERIN_*`, `DLG_MARA_*`,
`DLG_AGNES_*`, `DLG_CRONE_*`, `DLG_MATTHEW_*`, `DLG_VOICE_*`).
Особенно важны единые имена и обращения (艾格尼丝, 玛拉, 马太, 塞维林), смысл выбора,
естественная устная речь и длина субтитров. После правок снова запустить `validate_data.gd`
и пройти сцены с интерфейсом на китайском.

## Машинная вычитка zh_CN (2026-10-14)

**Это не вычитка носителем.** Проход сделан моделью (Claude) по всем 1118 строкам `zh_CN` против `en`/`ru`:
термины, смысл, пунктуация, длина подписей. Пункт «вычитка носителем языка» остаётся открытым — всё, что
перечислено выше, по-прежнему нужно показать человеку, для которого китайский родной.

### Что изменено (85 ячеек, только колонка zh_CN)

- **Непереведённое**: `ENEMY_ASH_ARCHER`, `ENEMY_ASH_ARCHER_LORE`, `TIP_ASH_ARCHER` были по-русски/по-английски.
- **Ошибки в именах**: `DLG_NOTE_BOOK_3` — 埃里安 → 埃利安; Офаним был в трёх написаниях (欧法尼 / 欧法尼姆 / 欧法宁).
- **Термины** по глоссарию: 练习场 → 练武场, 赐福 → 恩赐, 精华 → 精魄, 精锐 → 精英, 功绩 → 事迹, 首领 → 头目,
  天国 → 天堂, 吊死 → 绞死, 祈祷 → 祷告 (реплики Мары об Агнессе), 教团 → 邪教, 长魂 → 长老之魂;
  «parry» в описаниях даров и деяний было 格挡 (блок) — стало 招架; «不要害怕» → «不要惧怕» в обоих местах.
- **Описания даров**: одна механика — одна формула (治疗次数+1, 移动速度+N%, 攻击速度+N%, 受到的伤害降低N%).
- **Смысл**: `BESTIARY_HINT_MEET` и `ENEMY_POSSESSED_VILLAGER_LORE` приписывали пол (他) — теперь нейтрально;
  `DLG_AGNES_SILENCE` «没有人在听» не стыковалось с ответом «有东西在听»; `SKIN_EMBER_DESC`, `SKIN_BONE_WHITE_DESC`,
  `ENEMY_OPHANIM_SEAL_LORE`, `AREA_ASHES_SUB`, `ABILITY_ABSOLUTION_DESC` (каждая *смерть врага* снимает два),
  `DLG_CH1_PREACHER_VOICE_NO`, три описания боссов из бестиария (обрезанный смысл, «猎人»);
  `TELEMETRY_BODY` терял «без аккаунта»; `CHEST_RELIQUARY_PROMPT` — не крышка гроба; `RUN_TO_BE_CONTINUED` — ворота деревни, не города;
  `SETTINGS_MOUSE_AIM_HINT` — щита у героя нет; `OMEN_PROCESSION` 游行 (демонстрация) → 巡行.
- **Пунктуация**: `…` → `……`, ` — ` → `——`, `「」` → `“”`.

Новые иероглифы не понадобились: где правка требовала символа вне подмножества шрифта, она переформулирована,
чтобы не пересобирать `NotoSerifSC-Subset.ttf` параллельно с PR #59 (бинарный конфликт).
