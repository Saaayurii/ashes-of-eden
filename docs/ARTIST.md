# Художнику: как рисовать для Ashes of Eden с Claude

Ты рисуешь — Claude делает всё техническое: изучает референс, пишет промпты
для ChatGPT, режет и масштабирует картинки, собирает анимации, проверяет их,
показывает в игре и отправляет владельцу на проверку. Код открывать не нужно.

Как это устроено, коротко:

1. Ты даёшь Claude референс и говоришь, что нужно.
2. Claude открывает **твой** ChatGPT в Chrome, вставляет промпт и прикладывает
   картинки. **Enter нажимаешь ты** — сам Claude генерацию не запускает никогда
   (так требуют правила OpenAI, и так твой аккаунт в безопасности).
3. Claude забирает картинку в студию, доводит её до игрового пиксель-арта
   (рост, сетка пикселей, палитра) и проверяет.
4. Ты смотришь результат прямо в игре («Песочница» в студии).
5. «→ В игру» — отправка владельцу. Он смотрит и вливает. Сломать игру
   ты не можешь: всё проходит через его проверку.

## Установка (один раз, ~30 минут)

1. **GitHub.** Зарегистрируйся на <https://github.com> и пришли владельцу свой
   логин — он даст доступ к репозиторию. Прими приглашение из письма.
2. **GitHub Desktop** — <https://desktop.github.com>. Войди своим аккаунтом,
   File → Clone repository → `Saaayurii/ashes-of-eden`. Папку запомни
   (обычно `Documents/GitHub/ashes-of-eden`).
3. **Google Chrome** — <https://www.google.com/chrome/>, и в нём расширение
   **Claude in Chrome** (Chrome Web Store → «Claude»). Войди в него своим
   аккаунтом Claude. В этом же Chrome войди в <https://chatgpt.com>.
4. **Claude desktop** — <https://claude.ai/download>. Войди, открой вкладку
   **Code**, выбери папку игры из шага 2.
5. Скажи Claude: **«Установи всё для работы с артом»**. Он запустит
   `tools/setup_artist.sh` (Python-библиотеки, Node, инструменты ref2game)
   и скажет, если чего-то не хватает на компьютере (например, попросит
   поставить Node.js — <https://nodejs.org>, кнопка LTS).
6. Открой студию <https://saaayurii.github.io/ashes-of-eden/studio/> в Chrome,
   справа вверху **Войти** → через GitHub. Один раз.

Готово. Дальше — только разговор с Claude.

## Что говорить Claude

| ты говоришь | что будет |
|---|---|
| «Вот референс, сделай врага» (+ картинка) | спросит пару вещей (на кого похож в бою, какие анимации), изучит референс и начнёт |
| «Вот референс, сделай персонажа» / «…NPC» | то же, без боевой части |
| «Сделай фон по этому референсу» | слои задника для студии |
| «Нажала» / «готово» | заберёт картинку из ChatGPT (спросит перед скачиванием) |
| «Кадр 3 не такой» / «тут он другой» | перерисует этот кадр правкой одобренного |
| «Не похож на референс» | сравнит, назовёт 2–3 главных отличия и исправит их |
| «Покажи в игре» | песочница: твой персонаж в игре через пару секунд |
| «Отправь в игру» | отправка владельцу, ссылка в «Моих отправках» |
| «Что с моими отправками?» | что проверено, что влито, что просят исправить |
| «Обнови всё» | подтянет свежую версию игры и инструментов |

Несколько правил, которые Claude соблюдает сам, но полезно знать:

- **Одна анимация — один новый чат ChatGPT.** В длинном чате персонаж
  постепенно «уплывает». Первый кадр рисуется по референсу, следующие —
  правкой одобренного кадра в том же чате.
- **Размер в пикселях ChatGPT не слушается** (просили 44 — рисовал 87),
  поэтому про размер в промпте нет ни слова: рост и сетку ставит студия.
- Картинка героя (`tools/studio/refs/elian_style_idle.png`) прикладывается
  только как образец **масштаба и палитры** — не чтобы рисовать рыцаря.
- Если что-то непонятно или Claude ошибся — так и скажи ему, по-русски.

## Для владельца: настройки GitHub

Чтобы её работа попадала в `main` только через тебя:

1. Она уже в репозитории (Collaborators, роль **Write**) — проверь, что роль
   именно Write, не Admin: Admin может обойти правила ветки.
2. Settings → Branches → Add branch ruleset (или classic protection) для `main`:
   - Require a pull request before merging, **1 approval**;
   - **Require review from Code Owners** (файл `.github/CODEOWNERS` = ты);
   - Require status checks to pass: `Validate data & localization`
     (job `validate` из `ci.yml`);
   - Block force pushes; Restrict deletions;
   - не добавляй её в bypass list.
3. Settings → Actions → General → Workflow permissions: оставь как есть —
   студийный робот (`studio-robot.yml`) пушит только в `studio/…` ветки.

Её Claude дополнительно не может пушить в `main`, делать force-push и
`gh pr merge` (`.claude/settings.json`, deny), но настоящая защита —
правила ветки на GitHub.
