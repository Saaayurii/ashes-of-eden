Элиана повесили и закопали за оградой. Он всё равно поднялся.

Вид сбоку, быстро и прощающе — в духе Dead Cells снаружи; серьёзная, намеренно неоднозначная
история внутри, для тех, кому она нужна. Игру можно пройти, не прочитав ни слова, и она всё
равно будет о чём-то.

> **Статус — прототип, `v0.1.0-dev`.** Проходится от начала до конца: 15 комнат в 8 областях,
> 14 видов врагов, включая мини-босса и босса с двумя фазами, 36 даров, 13 диалоговых деревьев
> с ветвлением, которое мир запоминает, четыре языка, онлайн-кооп и дуэль один на один
> с кроссплатформенностью. Чего пока нет — [docs/ROADMAP.md](docs/ROADMAP.md).

**Бесплатно. Open source. Без pay-to-win. Без лутбоксов.** — [как игра зарабатывает](docs/MONETIZATION.md)

## Про что это

|  |  |
|---|---|
| **Ангелы — не добро. Демоны — не зло.** | Небо хочет мир без страданий — и без выбора. Бездна хочет свободу со всеми её последствиями. Элиан — единственное, что может сказать «нет» обоим. |
| **Геймплей намеренно простой.** | Бежать, прыгать, перекатываться, бить, парировать. Зачистил комнату — прошёл в дверь — взял дар — дальше. |
| **Сюжет за тобой наблюдает.** | Каждый дар и каждый ответ тихо сдвигает три скрытых счётчика — Благодать, Искушение, Воля. Мир реагирует. Цифр не показывают никогда. |
| **Двенадцать разных финалов одной ночи.** | Четыре исхода разговора со священником на три склонения забега. Ни один из них не «хороший». |
| **Сделано, чтобы форкать.** | Враги, дары, комнаты, диалоги и переводы — обычные JSON и CSV. Контент добавляется без движка. |
| **Можно вдвоём.** | Весь сюжет проходится в кооперативе, плюс дуэль один на один. Ноутбук, телефон и вкладка браузера играют в одном матче. |

## Первые пять минут

Сначала говорит Элиан — по чёрному экрану: что он помнит о верёвке и где кончается его
собственное знание. Потом занавес поднимается, ангел сообщает ему, что он должен был умереть,
и ночь начинается, ни на секунду не забирая управление.

За что его повесили, он узнает только через тринадцать комнат, от священника — и только если
спросит. Посекундно: [docs/CORE_LOOP.md](docs/CORE_LOOP.md). Вся глава целиком, кто где стоит
и какой выбор кто запомнит: [docs/CHAPTER1.md](docs/CHAPTER1.md).

**Озвучка.** Сюжетные сцены озвучены на всех четырёх языках, локально, через
[Piper](https://github.com/OHF-Voice/piper1-gpl) — MIT, офлайн, без платных сервисов, ничего
не уходит с машины. Это заглушки в том же смысле, что и сгенерированные звуки: настоящая
запись живого человека, положенная по тому же пути, побеждает, а реплика без записи остаётся
субтитром — так игра работала всегда. Как устроен каст и что нужно, чтобы его заменить:
[docs/VOICE.md](docs/VOICE.md).

## Управление

| Действие | Клавиатура | Геймпад | Касание |
|---|---|---|---|
| Движение | `A` / `D`, стрелки | левый стик | джойстик (левая половина) |
| Прыжок / двойной прыжок | `Space` / `W` / `Up` | A | зелёная кнопка |
| Перекат (неуязвимость) | `Shift` / `K` | B | синяя кнопка |
| Удар с воздуха | `S` / `Вниз` в прыжке | стик вниз | стик вниз |
| Цепляние за стену · прыжок от стены | держать в стену в воздухе, затем прыжок | стик в стену, затем A | стик в стену, затем зелёная |
| Удар | `J` / левая мышь | X | золотая кнопка |
| Блок (удерживать) · парирование (нажать перед самым ударом) | `L` / правая мышь | RB | голубая кнопка |
| Заговорить | `E` | A | нажать подсказку |
| Пропустить сцену | любая кнопка | любая кнопка | касание |
| Пауза / настройки | `Esc` | Start | — |

Любую клавишу можно переназначить в настройках.

## Запуск

**Редактор — то, в чём разрабатывают.** Установить [Godot 4.7](https://godotengine.org/download)
и открыть `project.godot`, либо:

```bash
brew install --cask godot        # macOS
make editor
```

**Docker — тот же образ, что в CI**, для валидации, тестов и сборок:

```bash
make image      # собрать образ один раз (~1 ГБ: Godot + export templates)
make validate   # проверить все файлы данных и все 4 локали
make test       # headless-прогон игрового цикла от начала до конца
make net-test   # сетевой стенд в двух процессах: кооп и дуэль, хост и выделенный сервер
make server     # выделенный хост для двух браузеров, на ws://localhost:8910
make build      # экспорт Windows / Linux / macOS / Web в ./build
make web        # экспорт Web и сервер на http://localhost:8080
make android    # отладочный APK (сначала `make android-image`)
```

<details>
<summary><b>Пересборка генерируемых ассетов</b></summary>

Арт, звук и речь собираются детерминированными скриптами, поэтому их не нужно коммитить
руками, а пересборка не мусорит в истории:

```bash
python3 tools/audio/generate_voices.py     # голос каждой твари: тревога / атака / боль / смерть
python3 tools/audio/generate_sfx.py        # звуковые заглушки
python3 tools/audio/generate_alignment_layers.py  # три музыкальных слоя, по одному на путь
python3 tools/audio/generate_speech.py     # озвучка реплик, 4 языка (нужен pip install 'piper-tts[zh]', см. docs/VOICE.md)
python3 tools/rooms/generate_rooms.py      # генерируемые комнаты
python3 tools/rooms/painted_rooms.py       # нарисованные
python3 tools/art/make_secret_walls.py     # кирпичная кладка поверх тайников
```

Скриншоты для README снимаются из самой игры:

```bash
godot --path . -s scripts/tools/promo_screenshots.gd -- /tmp/shots   # в окне, не headless
```

</details>

## Игра вдвоём

Главное меню → **Игра вдвоём**. Один выбирает «Сюжет вдвоём» или «Дуэль» и нажимает
**Создать игру** — на экране появится адрес, который надо продиктовать. Второй вводит его
и нажимает **Присоединиться**. Оба нажимают «Готов», хост — «Начать». Порт по умолчанию `8910`.

Кроссплатформенность в обе стороны: транспорт — WebSocket, поэтому хост на компьютере
обслуживает и браузер, и телефон одновременно. Браузер хостить не может — он не умеет слушать
входящие соединения, — так что если оба в браузере, поднимите выделенный сервер:

```bash
make server                                           # ws://localhost:8910
godot --headless -- --server --port=8910 --mode=pvp   # без Docker
```

Что решает хост, а что ваша сторона: [docs/MULTIPLAYER.md](docs/MULTIPLAYER.md).

## Структура проекта

```
data/            игра как JSON — дары, враги, диалоги, сцены, главы, записки
localization/    strings.csv с колонками en / ru / uk / zh_CN
scenes/          сцены Godot: игрок, враги, комнаты, забег, интерфейс
scripts/
  autoload/      глобальные системы: EventBus, Data, Game, Audio, Settings, Net, Profile
  combat/        AbilitySystem — применяет дары из данных к игроку
  pvp/           duel.gd — матч один на один, раунды и счёт
  tools/         валидаторы, смоук-тесты и съёмка скриншотов (headless, используются в CI)
assets/
  audio/voice/   озвученные реплики, по папке на локаль (tools/audio/generate_speech.py)
  shaders/       туман и вода для комнат и меню
tools/
  audio/         генераторы звука, музыки и речи + каст голосов
  rooms/         генераторы комнат, нарисованных и процедурных
  art/           сборка спрайтов и пропсов
  docker/        entrypoint и конфиг nginx для сборочного образа
content/         (вне git) официальные ассеты из приватного репозитория — опционально
docs/            GDD, игровой цикл, глава I, озвучка, монетизация, планы, форматы данных, локализация
```

## Как помочь

Переводы, дары, враги и диалоги — самое простое начало: почти везде достаточно JSON или CSV,
движок открывать не нужно. См. [CONTRIBUTING.md](CONTRIBUTING.md) и
[docs/DATA_FORMATS.md](docs/DATA_FORMATS.md). CI проверяет каждый pull request: файлы данных,
все четыре локали и headless-прогон всего игрового цикла.

Что нужно прямо сейчас: второй проход по китайскому тексту носителем языка
([docs/LOCALIZATION_REVIEW.md](docs/LOCALIZATION_REVIEW.md)) и живая озвучка
([docs/VOICE.md](docs/VOICE.md)).
