# Ashes of Eden — Пепел Эдема

Open-source 2D пиксельный action-roguelite о человеческой душе, которую не могут забрать ни Небо, ни Бездна.
Сверху — простой быстрый аркадный геймплей; внутри — серьёзный сюжет, где не всё однозначно.

> **Статус: прототип (v0.1-dev).** Одна комната, два типа врагов, девять даров, два диалога, четыре языка,
> онлайн-кооп и дуэль один на один с кроссплатформенностью.
> Графика — цветные прямоугольники, и это сознательно: см. [docs/ROADMAP.md](docs/ROADMAP.md).

## Идея

- **Ангелы — не добро. Демоны — не зло.** Небо хочет мир без страданий — и без выбора. Бездна хочет свободу — со всеми её последствиями. Игрок — единственное существо, способное сказать «нет» обоим.
- **Геймплей намеренно простой.** Ходишь, бьёшь, уклоняешься. Пережил волну — выбрал дар — дальше. Всю игру можно пройти, не прочитав ни слова.
- **Сюжет необязателен, но он за тобой наблюдает.** Каждый дар и каждый выбор сдвигает три скрытых счётчика — Благодать, Искушение, Воля. Мир реагирует. Цифр никто не показывает.
- **Сделано, чтобы форкать.** Враги, дары, диалоги и переводы — обычные JSON/CSV. Контент добавляется без движка.
- **Можно вдвоём.** Весь сюжет проходится в кооперативе, плюс дуэль один на один. Ноутбук, телефон и вкладка браузера могут играть в одном матче — [docs/MULTIPLAYER.md](docs/MULTIPLAYER.md).

**Бесплатно. Open source. Без pay-to-win. Без лутбоксов.** — [как игра зарабатывает](docs/MONETIZATION.md)

Полный дизайн: [docs/GDD.md](docs/GDD.md). Первые пять минут посекундно: [docs/CORE_LOOP.md](docs/CORE_LOOP.md).

## Игра вдвоём

Главное меню → **Игра вдвоём**. Один выбирает «Сюжет вдвоём» или «Дуэль» и нажимает
**Создать игру** — на экране появится адрес, который надо продиктовать. Второй вводит его
и нажимает **Присоединиться**. Оба нажимают «Готов», хост — «Начать». Порт по умолчанию `8910`.

Кроссплатформенность в обе стороны: транспорт — WebSocket, поэтому хост на компьютере
обслуживает и браузер, и телефон одновременно. Браузер хостить не может (он не умеет слушать
входящие соединения), так что если оба в браузере — поднимите выделенный сервер:

```bash
make server                                           # ws://localhost:8910
godot --headless -- --server --port=8910 --mode=pvp   # без Docker
```

Подробности и разделение ответственности (что решает хост, а что ваша сторона):
[docs/MULTIPLAYER.md](docs/MULTIPLAYER.md).

## Запуск

**Редактор (для разработки):** установить [Godot 4.7](https://godotengine.org/download) и открыть `project.godot`.

```bash
brew install --cask godot
make editor
```

**Docker (валидация, тесты, сборки — тот же образ, что в CI):**

```bash
make image      # собрать образ один раз (~1 ГБ: Godot + export templates)
make validate   # проверить данные и все 4 локали
make test       # headless-прогон игрового цикла от начала до конца
make net-test   # сетевой стенд в двух процессах: кооп и дуэль, хост и выделенный сервер
make server     # выделенный хост для двух браузеров, на ws://localhost:8910
make build      # экспорт Windows / Linux / macOS / Web в ./build
make web        # экспорт Web и сервер на http://localhost:8080
```
